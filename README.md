# mxd-music-player

A lightweight, minimalist music player for Linux and Windows.

Dark\Light theme in GruvBox color scheme. <br>
Supports boosting audio levels up to 200%. <br>
Dynamic audio visualizer. <br>
Real-time music search in the selected directory. <br>

----------------------------------------------------------------

## Core Specs
Fully Portable: Saves both `settings.cfg` and `color_config.cfg` strictly into the program folder. <br>
Integrated Spectrum: Real-time audio visualizer on the main screen. <br>

----------------------------------------------------------------

## Installation for Linux
1. Download the x86_64\x86_32 file from the releases page. <br>
2. Place the executable file in the folder you need <br>
3. Grant executable permissions to the file: `chmod +x mxd-music-player.x86_64` \ `chmod +x mxd-music-player.x86_32` <br>
4. Launch the player: `./mxd-music-player.x86_64` \ `./mxd-music-player.x86_32` <br>

## Installation for Windows
1. Download the x86_64\x86_32 .exe file from the releases page. <br>
2. Place the executable file in the folder you need <br>
3. Launch the player: mxd-music-player.exe <br>

----------------------------------------------------------------

## Keyboard Controls
`[ SPACE ]` > Play / Pause <br>
`[ WHEEL ]` / `[ CTRL + UP / DOWN ]` > Volume (0-200%) <br>
`[ CTRL + LEFT / RIGHT ]` > Seek 10s Backward / Forward <br>
`[ ESC ]` > Close Window <br>
